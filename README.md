## 文件说明

- 文件按类别和课程归档；内容保持原样，没有重排、压缩或改写 PDF。
- 完全相同的副本只存一份；原文件名、来源文件名对应关系、字节数和 SHA-256 记录在 [catalog.json](catalog.json)。
- 试卷包保持 ZIP/RAR 原格式；部分包含答案，是否包含答案以具体文件为准。
- 笔记与讲义按原文件归类，不将其作者身份默认归为仓库维护者。
- 教材与参考资料单独归类，不作为个人原创成果展示。
