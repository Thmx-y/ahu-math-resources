# 专业课资料

安徽大学数学相关课程的往年试卷、练习、笔记、讲义与参考资料，独立归档，不包含个人网页代码。

目前收录 237 份不重复资料，覆盖 11 门课程：常微分方程、复变函数、概率论、高等代数、解析几何、近世代数、实变函数、数理统计、数学分析、数值分析、C++程序设计。

## 资料分类

- [往年真题及练习](往年真题及练习/)：202 份。
- [笔记与讲义](笔记与讲义/)：26 份。
- [教材与参考资料](教材与参考资料/)：9 份。

资料按课程分目录，保留中文名称。PDF、Word、演示文稿和压缩包均保持原始内容。
