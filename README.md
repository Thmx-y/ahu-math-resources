# 专业课资料

数学专业课往年真题及相关学习资料的独立归档，不包含个人网页代码，也不进行网页部署。

首批收录 **20 份资料**，涉及 **7 门课程**。原有 24 个文件中的 4 份完全重复副本仅保留一份，源文件夹未作修改。

## 资料分类

- [往年真题及练习](往年真题及练习/)：11 份，包含试卷、单元测试及部分答案。
- [笔记与讲义](笔记与讲义/)：3 份，包含知识点整理、专题材料和讲义。
- [教材与参考资料](教材与参考资料/)：6 份，包含教材、学习指导书和习题参考资料。

各类别下按课程分目录：数学分析、常微分方程、近世代数、实变函数、数理统计、复变函数和概率论。
